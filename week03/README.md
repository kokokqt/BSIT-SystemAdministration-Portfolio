# Week 3 – Enterprise Server Deployment and Operating System Installation

## Project Overview

This project focuses on the deployment, installation, configuration, verification, and documentation of an Ubuntu Server virtual machine.

## Learning Objectives

- Install Ubuntu Server in a virtual machine.
- Configure essential server settings.
- Enable SSH.
- Verify server functionality.
- Understand BIOS and UEFI.
- Understand the Ubuntu boot process.
- Compare enterprise operating systems.
